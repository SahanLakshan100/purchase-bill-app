# Purchase Bill Management System

A full-stack application built for the Enhanzer Full Stack Developer assessment. It demonstrates a login page that authenticates against an external POS API, and a dynamic Purchase Bill form with real-time calculations.

## 🛠️ Technology Stack

| Layer | Technology |
|---|---|
| Frontend | Angular 22, Angular Material, TypeScript |
| Backend | ASP.NET Core 8 Web API, C#, Entity Framework Core 8 |
| Database | SQL Server Express |
| Authentication | JWT Bearer tokens |

## 🚀 Setup Instructions

### Prerequisites
- .NET 8 SDK
- Node.js 18+ (and Angular CLI)
- SQL Server Express running on `localhost\SQLEXPRESS`
